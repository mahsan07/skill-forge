# Roadmap

## Phase 1: contract and local demo

- Skill template generator
- Frontmatter validator
- Naming and length checks
- Example prompt format
- Public-scrub checklist
- Quality rubric

## Later phases

- CLI scaffolder
- Schema validation
- Fixture-based tests
- Provider adapters
- Skill registry and compatibility metadata

## Release rule

Do not describe a phase as complete until the implementation, tests, documentation, and a reproducible demo all agree.
