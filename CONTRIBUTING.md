# Contributing

Focused bug reports, tests, documentation fixes, and small portability improvements are welcome.

1. Open an issue describing the problem and expected behavior.
2. Keep the change within this repository's independent product boundary.
3. Add or update a test for behavior changes.
4. Run `python -m unittest discover -s tests -v`.
5. Confirm examples contain no credentials, private endpoints, personal data, or proprietary content.
6. Submit a concise pull request explaining the user-visible outcome and verification evidence.

Please avoid generated file dumps, unrelated refactors, hidden network dependencies, and claims that are not demonstrated by tests or examples.
